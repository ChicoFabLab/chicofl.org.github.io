## Marquee Files
All flyers must be in a landscape 1376x768 format
All of the flyer files must be a png or apng file with the .png file extention
All file must be named flyer_#.png where # is a one or two digit number ranging from 1 to 50
flyers can be deleted and added to the folder as needed ... files that are in the folder that do not
match the file naming outlined above will be ignored ...
